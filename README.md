# 参考文库

本参考文库的创立，是为了记录并保存各类少见的亚文化、政治与民间材料。

这些材料多不在主流的出版与流通渠道内，散佚极快：有的印量极小，有的从未正式出版，有的只在特定的圈子里流传过一阵，还有的早已绝版多年。它们对研究有资料价值；若不收集存档，过些年便无处可寻。本库只做保存，不做推荐。

所藏书籍与文件不代表上传者的立场，也不代表上传者一定同意其中的观点。收录一本，只意味着它曾被写出、被读过，对某段历史或某种思潮起过作用，值得留一份底稿。

请读者自行判断。对书中的极左翼与极右翼观点，尤须警惕。
