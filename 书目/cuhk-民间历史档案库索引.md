# 香港中文大学「民间历史档案库」全量扫描索引

## 是什么

香港中文大学图书馆的「民间历史档案库」（Folk History Archive），来源标 USC Collection China Studies，即原中国研究服务中心（Universities Service Centre）收藏。站方说明：**基于版权考虑，大部分文章新站只给元数据，仅 70 篇长篇＋400 余篇短篇为独家全文**。

也就是说，这库里绝大多数条目点进去只有题录，没有正文。全文的那一百来篇才是能用的。

## 文件

- 文件名：`cuhk-民间历史档案库-全量扫描索引.json`
- 字节：3,056,042

- 结构：对象数组，每项四个字段

```json
{
  "uid": "C1A000S01",
  "title": "(404)",
  "author": "",
  "has_cq": false,
  "text": "…抓到的正文或错误页文字…"
}
```

- `uid` —— 站内编号，拼进 URL 即 `https://libguides.lib.cuhk.edu.hk/blogs/folk-history-archive/fulltext/{uid}`
- `title` / `author` —— 题名与作者
- `has_cq` —— 是否抓到正文（`text` 里是正文还是 404 页，看这个加 `text` 开头判）
- `text` —— 抓下来的内容。**注意 `title` 为 `"(404)"` 的条目是空壳**，抓取时页面已不存在，别当成「有这一篇」用

## 用法

**先筛，再抓。** 索引里混着相当比例的 404，直接按 uid 批量重抓会浪费轮次。筛 `has_cq -eq $true` 且 `text` 不是以 ` (404)` 开头的那批。
