# 文献资料归档

一个个人研究用的文献仓库。收三类东西：**能拿到全文的书**、**外部档案库的抓取索引**、**自己写的专题研究笔记**。

不是书单搬运站，也不做目录集合站。每一件进来的东西都有确定的来源、可校验的字节、以及一句「这份能用在哪」。

## 目录

| 目录 | 放什么 | 不放什么 |
|---|---|---|
| `专著/` | 研究专著全文（PDF），多为绝版或大陆未引进 | 通俗读物、教材 |
| `理论/` | 理论著作的中译本全文（PDF） | 只有英文的、只有摘要的 |
| `索引/` | 外部档案库的全量抓取索引（JSON），供日后复查不再重扫 | 单篇正文（单篇归各专题笔记） |
| `书目/` | 每件的版本、来源、校验值、内容提要、引用口径 | 正文 |
| `研究笔记/` | 自撰的专题框架、资料路线、判据与结论 | 原文摘抄拼贴 |

## 收录原则

**进得来的：**
- 有确定版本信息（出版社、年份、ISBN 或 DOI）的全文。
- 能验字节的文件：记录大小、SHA-256、下载路径；同一个文件有多个副本时说明差别（扫描件与文字层的用途完全不同）。
- 外部数据库的全量索引：抓一次存下来，写清抓取日期与站点状态，免得下次重扫。

**进不来的：**
- 二手转录、来源不明的摘录、没有出处的「据说」。
- 只有目录页没有正文的记录。
- 网页剪藏、公众号转载。

## 引用约定

- 引原文一律以**有文字层的那一份**为准，扫描件只用来看版式、核页码、对图。
- 同一本书有两个副本时，`书目/` 里会写明哪一份可检索、哪一份只能看。
- 港版书用港版页码，书内页码与 PDF 页码的偏移在每个 `书目/` 文档里单独给出。

## 版权

仓库里的全文文件，著作权均属原作者与出版方。此处仅作个人研究存档，未获授权再分发。引用请回纸本或正版电子版核对页码与文字。

如权利人要求移除，开 issue 说明，删文件保留书目条目。

## 关于研究笔记

`研究笔记/` 里的东西是自己写的——框架、判据、资料在哪、哪些路走过是死的。写的时候按「下次接手的人能直接用」这个标准来，不抄原文，不写读后感。

来源与推导过程在每篇末尾附注，方便回头查。
