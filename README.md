# 参考文库

**警告！**

所藏书籍与文件不代表上传者的立场，也不代表上传者一定同意其中的观点。警惕藏书中的极端主义观点，歪曲历史说法，和纳粹观点。

---

本参考文库创立旨在保存大量无法通过正规渠道出版流通的禁书/民间组织材料/个人研究文献/亚文化书籍。它们散佚极快，难以保存，但是对历史研究和政治探讨有帮助。如果不加以保存，以后无处可寻。很多书籍是上传者自行翻译的。
